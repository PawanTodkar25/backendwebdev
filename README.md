# Event & Attendee Management System

## Brief Description
A full-stack web application designed for organizers to manage events and handle attendee registrations. The system features a public-facing page to create events, set maximum venue capacities, and register attendees. It also includes a secure, password-protected admin directory to search through attendees, prevent duplicate registrations, and manage (delete) event and attendee records dynamically.

## Technologies Used
* **Frontend:** HTML5, CSS3, Vanilla JavaScript
* **Backend:** Node.js, Express.js (REST API)
* **Database:** SQLite
* **Middleware/Tools:** CORS, Fetch API
